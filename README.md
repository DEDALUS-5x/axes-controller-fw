# Axes Controller Board firmware

Bare-metal firmware (C, STM32 HAL) for the Axes Controller Board
(STM32H723ZGT6), the motion controller of the
[DEDALUS](https://dedalus-5x.github.io/dedalus-docs/) five-axis printer. It
runs the control loops of two DC-servo axes and of the closed-loop stepper
axes in a 10 kHz interrupt and exchanges setpoints and telemetry with a
Raspberry Pi over SPI.

Hardware: <https://github.com/DEDALUS-5x/axes-controller-board>

## Build and flash

Requirements: GNU Arm Embedded toolchain (`arm-none-eabi-gcc`), GNU Make,
OpenOCD with an ST-LINK, and STM32CubeMX.

1. The STM32H7 HAL and CMSIS (`Drivers/`) are not stored in this repository.
   Open `axes-controller-fw.ioc` in STM32CubeMX and generate the code
   (toolchain: Makefile) to create them. Code generation rewrites `Makefile`:
   add `Core/Src/ctrl.c` and `Core/Src/handlers.c` back to `C_SOURCES`
   afterwards.
2. Build with `make`.
3. Flash with
   `openocd -f openocd.cfg -c "program build/axes-controller-fw.elf verify reset exit"`.
